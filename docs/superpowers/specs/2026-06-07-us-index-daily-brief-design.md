# 美股指数每日简报设计

## 目标

每天在美股交易日收盘后，为长期定投纳斯达克100和标普500场外基金的用户生成中文复盘邮件。报告用于辅助观察和理解市场，不代替用户决策，也不针对某一家基金公司的产品、额度、净值或申购状态做判断。

## 用户策略

- 长期定投纳斯达克100和标普500相关场外基金。
- 上涨或没有明显下跌时维持正常定投。
- 下跌时可按个人习惯适当增加总申购额，再自行分配至不同基金公司。
- 不根据日报执行机械交易，不需要日报给出主动减仓指令。
- 场外基金通常为 T+2 且可能限购，因此建议只描述指数层面的市场环境，不假定最终成交价格或可申购额度。

## 运行与投递

- 使用 GitHub Actions 在云端运行，不依赖个人电脑保持开机。
- 目标时间为北京时间每天 08:00。
- 仅在获得新的美股交易日收盘数据时发送；周末、美国休市日及重复行情不发送。
- GitHub Actions 定时任务可能出现数分钟级延迟，报告不得宣称精确到 08:00 到达。
- 邮件通过 Gmail SMTP 发送至环境变量 `REPORT_RECIPIENT` 指定的地址。
- Gmail 应用专用密码仅保存在 GitHub Actions Secret 中，不写入仓库、日志或报告。
- 邮件正文采用适合手机阅读的单栏响应式 HTML，同时生成完整 HTML 报告作为归档或网页链接。

## 数据范围

### 核心市场

- 纳斯达克100：优先使用官方指数数据；必要时使用 QQQ 作为可交易代理。
- 标普500：优先使用官方指数数据；必要时使用 SPY 作为可交易代理。
- 补充参考：VIX、美国10年期国债收益率、美元指数以及主要美股指数期货。

### 市场指标

- 上一交易日收盘涨跌幅。
- 最近 5 个和 20 个交易日表现。
- 距近 20 日、60 日及历史高点的回撤。
- 20 日实现波动率或等价稳定指标。
- 价格相对 20 日、50 日和 200 日均线的位置。
- 纳斯达克100与标普500的相对强弱。

### 新闻

- 美联储讲话、利率预期及重要宏观数据。
- 对指数影响显著的大型科技公司事件。
- 美国财政、贸易、监管及地缘政治事件。
- 只使用带发布时间和原始链接的新闻。
- 将事实、媒体观点和模型推断明确分开。
- 若无法确认某条新闻与指数涨跌的因果关系，使用“可能相关”而非确定性表述。

## 报告结构

1. 一句话结论：昨夜风险偏好和两大指数总体表现。
2. 行情表：纳斯达克100、标普500及补充指标。
3. 涨跌原因：列出最重要的三至五个新闻和数据驱动因素。
4. 定投观察：
   - `正常定投`
   - `正常定投，可略微增加`
   - `出现较明显回撤，可按原计划增加`
   - `波动较大，避免因单日新闻改变长期计划`
5. 风险提示：场外基金时差、T+2、汇率、限购及净值确认的不确定性。
6. 数据来源和原始新闻链接。

## 建议生成规则

建议由可复核规则先生成基础结论，再由 LLM 负责中文解释，不允许 LLM自行改变结论等级。

- 指数上涨、平盘或跌幅较小：`正常定投`。
- 单日下跌但中期回撤有限：`正常定投，可略微增加`。
- 单日明显下跌，或相对近期高点形成更深回撤：`出现较明显回撤，可按原计划增加`。
- 当波动率异常升高、重大事件尚未落地或数据冲突：保留上述基础等级，并追加`波动较大，避免因单日新闻改变长期计划`。

具体阈值作为可配置参数，并在实施阶段用历史样本验证。默认规则应保守，避免因普通的日内波动频繁触发“明显加仓”措辞。

## 系统组件

- `market-fetcher`：获取并校验指数、代理 ETF 和宏观指标数据。
- `news-fetcher`：从公开 RSS 或 API 获取带链接和时间戳的新闻。
- `signal-engine`：计算回撤、趋势和波动，生成确定性的基础建议。
- `brief-writer`：基于结构化数据生成中文解释，不直接决定仓位等级。
- `renderer`：输出移动端邮件 HTML 和完整网页报告。
- `mailer`：通过 Gmail SMTP 投递，隐藏认证信息。
- `run-state`：记录最后已发送的美股交易日，防止重复发送。

## 数据流

GitHub Actions 定时触发后，先判断是否存在新的美股收盘数据。若不存在则正常退出。若存在，则抓取并校验行情和新闻，计算指标与基础建议，生成解释和 HTML，发送邮件，最后更新已发送交易日状态。任何关键行情数据缺失时不发送仓位建议，只发送数据异常说明或终止本次任务。

## 错误处理

- 单一新闻源失败：继续运行，并在来源区标注缺失。
- 核心指数数据缺失或日期不一致：不生成建议，不发送正常日报。
- LLM 调用失败：发送仅含确定性指标和规则结论的降级版日报。
- 邮件发送失败：任务失败并保留日志，下次运行可重试，但必须通过交易日状态避免重复邮件。
- Secret 不得出现在异常消息、构建产物或调试日志中。

## 验证

- 用历史上涨、普通下跌、显著回撤和高波动交易日测试建议分级。
- 测试周末、美国休市日和重复运行不会重复发信。
- 测试行情缺失、新闻源失败、LLM 失败和 SMTP 失败的降级行为。
- 在手机宽度下检查邮件标题、行情表、链接和中文文本不溢出。
- 首次部署后手动运行一次，并向测试地址发送样例邮件，再启用正式定时任务。

## 非目标

- 不预测下一交易日涨跌。
- 不承诺收益，不输出确定性买卖指令。
- 不追踪具体基金公司的限购、溢价或申购状态。
- 不自动下单，不连接券商或基金销售账户。
- 不因短期新闻建议清仓、止损或停止长期定投。
